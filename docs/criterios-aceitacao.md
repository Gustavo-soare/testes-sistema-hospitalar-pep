# Critérios de Aceitação

Os critérios de aceitação estabelecem as condições que deverão ser atendidas pelo sistema para que os requisitos funcionais sejam considerados implementados corretamente. Eles serão utilizados como referência durante a execução dos casos de teste.

| ID | Critério de aceitação |
|---|---|
| CA01 | O sistema deve permitir o acesso quando o usuário informar credenciais válidas. |
| CA02 | A pesquisa deve localizar corretamente os pacientes cadastrados no sistema. |
| CA03 | O sistema deve apresentar os dados básicos correspondentes ao paciente selecionado. |
| CA04 | O prontuário eletrônico deve apresentar corretamente as informações disponíveis do paciente. |
| CA05 | Os campos de preenchimento devem aceitar informações em formatos válidos e apresentar mensagens quando os dados forem inválidos. |
| CA06 | O sistema deve impedir o salvamento quando os campos obrigatórios não estiverem preenchidos e apresentar uma confirmação quando o registro for realizado com sucesso. |

## Observação

Os critérios de aceitação foram definidos com base nos requisitos funcionais propostos para o fluxo de consulta e preenchimento do prontuário eletrônico. Antes da execução dos testes, eles deverão ser confrontados com as funcionalidades e regras efetivamente disponibilizadas pela aplicação escolhida.
