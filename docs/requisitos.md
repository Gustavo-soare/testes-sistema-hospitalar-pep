# Requisitos Funcionais

Os requisitos funcionais descrevem as funcionalidades que o sistema hospitalar deverá disponibilizar aos usuários durante o processo de consulta e preenchimento do prontuário eletrônico do paciente.

| ID | Requisito |
|---|---|
| RF01 | O sistema deve permitir o acesso por meio da autenticação do usuário, utilizando credenciais válidas. |
| RF02 | O sistema deve impedir o acesso quando forem informadas credenciais inválidas. |
| RF03 | O sistema deve permitir pesquisar pacientes previamente cadastrados, apresentando os registros correspondentes aos critérios informados. |
| RF04 | O sistema deve permitir visualizar os dados cadastrais básicos do paciente selecionado. |
| RF05 | O sistema deve permitir consultar as informações disponíveis no prontuário eletrônico do paciente, incluindo seu histórico de atendimentos. |
| RF06 | O sistema deve permitir cadastrar e editar informações básicas dos pacientes. |
| RF07 | O sistema deve validar o preenchimento dos campos obrigatórios, impedindo o salvamento de registros incompletos. |
| RF08 | O sistema deve validar as informações inseridas nos campos cadastrais, considerando os formatos e tipos de dados esperados. |
| RF09 | O sistema deve permitir salvar as informações cadastradas e manter os dados disponíveis para consultas posteriores. |
| RF10 | O sistema deve permitir agendar consultas por meio do calendário, associando o paciente ao profissional responsável, à data e ao horário do atendimento. |
