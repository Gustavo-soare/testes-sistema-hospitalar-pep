# Requisitos Funcionais

Os requisitos funcionais descrevem as funcionalidades que o sistema hospitalar deverá disponibilizar aos usuários durante o processo de consulta e preenchimento do prontuário eletrônico do paciente.

| ID | Requisito |
|---|---|
| RF01 | O sistema deve permitir o acesso por meio de autenticação do usuário. |
| RF02 | O sistema deve permitir pesquisar pacientes cadastrados. |
| RF03 | O sistema deve exibir os dados básicos do paciente selecionado. |
| RF04 | O sistema deve permitir consultar as informações disponíveis no prontuário eletrônico. |
| RF05 | O sistema deve permitir inserir informações básicas no prontuário eletrônico. |
| RF06 | O sistema deve validar os campos obrigatórios e permitir o salvamento das informações quando os dados estiverem corretos. |
