# Checklist de Testes

- [ ] O usuário consegue acessar o sistema?
- [ ] O sistema rejeita credenciais incorretas?
- [ ] É possível acessar a área de prontuários?
- [ ] É possível pesquisar um paciente cadastrado?
- [ ] O sistema informa quando um paciente não existe?
- [ ] Os dados básicos do paciente são exibidos?
- [ ] O prontuário pode ser consultado?
- [ ] É possível preencher as informações básicas?
- [ ] Os campos obrigatórios são identificados?
- [ ] Informações em formato inválido são rejeitadas?
- [ ] O sistema permite salvar informações válidas?
- [ ] Os dados continuam registrados após atualizar a página?
