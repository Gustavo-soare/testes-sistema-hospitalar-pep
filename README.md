# Testes de Software — Sistema Hospitalar PEP

**Aluno:** Gustavo Henrique Soares

**Disciplina:** SF022 — Engenharia de Software

**Professor:** Luís Felipe Schons Silva

## 1. Apresentação

Este projeto tem como objetivo aplicar os conceitos de
engenharia de software na avaliação de um sistema hospitalar
com prontuário eletrônico do paciente (PEP).

## 2. Aplicação analisada

Sistema hospitalar com funcionalidade de consulta e
preenchimento de informações básicas do prontuário eletrônico.

## 3. Objetivo

Verificar se o sistema permite localizar pacientes,
consultar informações cadastradas e inserir novos dados
no prontuário de maneira correta e segura.

## 4. Documentação

- Escopo do projeto
- Requisitos funcionais
- Critérios de aceitação
- Plano de testes
- Checklist
- Casos de teste
- Rastreabilidade

## 5. Resultados

Os resultados dos testes serão apresentados com os
respectivos status PASS ou FAIL e evidências.

## 6. Evidências

As capturas de tela da execução dos testes estarão
disponíveis na pasta evidencias.
